# InterviewMate AI 🎯

> **IBM SkillsBuild AICTE-2026 · Problem Statement #22 – Interview Trainer Agent**

An AI-powered interview practice platform built with **Python**, **Streamlit**, and **IBM Granite** (via IBM watsonx.ai). Candidates enter their profile, choose Technical or HR mode, receive personalised questions generated by IBM Granite, and get detailed feedback on their answers.

---

## Features

| # | Feature |
|---|---------|
| 1 | Candidate profile: name, job role, experience level, skills |
| 2 | Technical Interview or HR Interview mode |
| 3 | RAG — relevant questions pulled from a local JSON knowledge base |
| 4 | IBM Granite generates personalised questions from retrieved context |
| 5 | Candidate answers via text area |
| 6 | IBM Granite evaluates answers: score/10 · strengths · missing concepts · improvements · model answer |
| 7 | Overall performance report |

## Quick Start

### 1. Clone / download the project

```bash
cd InterviewMate-AI
```

### 2. Create a virtual environment (recommended)

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Set up credentials

```bash
cp .env.example .env   # or copy manually on Windows
```

Open `.env` and fill in:

```
WATSONX_API_KEY=<your IBM Cloud API key>
WATSONX_PROJECT_ID=<your watsonx.ai project ID>
WATSONX_URL=https://us-south.ml.cloud.ibm.com
```

> **How to get these values**
> 1. Create a free [IBM Cloud account](https://cloud.ibm.com/registration).
> 2. Create a **watsonx.ai** service instance.
> 3. Generate an API key at **Manage → Access (IAM) → API keys**.
> 4. Copy your **Project ID** from the watsonx.ai project settings.

### 5. Run the app

```bash
streamlit run app.py
```

## Security Notes

- API keys are loaded **only** from `.env` via `python-dotenv` — never hardcoded.
- `.env` and `interview_history.db` are listed in `.gitignore` — neither will ever be committed to git.
- All user-supplied text is sanitised (control characters stripped, length capped) before being injected into Granite prompts.
- Prompt injection patterns in candidate answers are detected and redacted before reaching Granite.
- Evaluation outputs are validated by Pydantic models: scores are clamped 0–10, fabrication claims stripped, required fields enforced.
- HR evaluations are checked for protected characteristic references (age, gender, race, etc.) and stripped automatically.
- The IBM watsonx.ai SDK client is cached per-process — credentials are read once, not on every API call.
